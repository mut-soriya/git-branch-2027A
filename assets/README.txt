KHMER FONT SETUP
-----------------
The site automatically switches to Khmer OS Battambang for information/body text and Khmer OS Muol Light for headings/navigation display text when Khmer mode is active.

The CSS uses the installed Windows font names, so no font file is redistributed in this project. If you have licensed .ttf/.otf/.woff2 files and want them bundled for visitors who do not have the fonts installed, place them in assets/fonts/ and update @font-face in css/style.css.
